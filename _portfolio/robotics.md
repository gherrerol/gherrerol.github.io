Assignments from Computer Vision Master at URJC, a university robotics subject built around ROS2 and the Unibotics simulation platform (Gazebo). Each one tackles a different piece of the classic robotics stack:

[![Reactive Control](/images/robotics/car.png)](/_portfolio/robotics/pid))

[**Assigment 1: Reactive Control**](/_portfolio/robotics/pid)

PD controller for line tracking in an autonomous F1 car, isolating the track in HSV space.

[![3D Reconstruction](/images/robotics/scene.png)](/_portfolio/robotics/3d))

[**Assigment 2: 3D Reconstruction**](/_portfolio/robotics/3d)

A stereo vision pipeline that triangulates a dense point cloud from the left and right cameras.

[![Autolocalization](/images/robotics/autolocalization.png)](/_portfolio/robotics/autolocalization/)

[**Assigment 3: Autolocalization**](/_portfolio/robotics/aautolocalization/)

Global positioning using AprilTags via PnP, combined with odometry.

[![End-to-End Visual Control](/images/robotics/visual.png)](/_portfolio/robotics/endtoend/)

[**Assigment 4: End-to-End Visual Control**](/_portfolio/robotics/endtoend/)

The same line-tracking task as assigment 1, learned using a CNN trained on labeled images.
